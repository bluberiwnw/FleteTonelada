# FleteTonelada

Aplicación web que conecta a empresas que necesitan transportar
carga pesada con transportistas independientes.

## Objetivo

Facilitar la cotización, publicación, asignación y seguimiento
de servicios de transporte de carga pesada.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- PHP 8
- MariaDB
- PDO
- Git y GitHub

## Roles del sistema

- Cliente
- Transportista
- Administrador

## Funcionalidades principales

- Registro e inicio de sesión.
- Cotización de fletes.
- Publicación y aceptación de cargas.
- Administración de unidades.
- Seguimiento de viajes.
- Confirmación de entrega mediante PIN.
- Simulación de pagos en garantía.
- Calificaciones.
- Panel administrativo.
